# exterayond — MD3 icon set

Two directions, both on the same 512 grid, palette and mark.

- **solid** — the exteraGram register: one tonal container, one bold mark.
- **soft** — the exteraless register: two scalloped fields whose edges follow the
  chevron, so the mark travels a cream channel instead of sitting on a backdrop.

Palette: deep `#175E45`, cream `#FBF6E8`, mint `#9FD5BB`, sand `#F3DC9B`.

Geometry: 512 grid; superellipse container (n=4.2); chevron `185,168 → 333,256 → 185,344`
with a 58 round stroke, apex on the horizontal axis, mouth opening left; soft fields are
made of tangent 96-unit scallops set 84 units off the chevron's outer edge, converging
4° toward the apex side.
